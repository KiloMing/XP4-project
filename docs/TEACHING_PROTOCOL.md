# 教学流程

目标：既交付可复核的 V1.0，也能独立理解、修改和调试核心流程。

1. 每次先读 CURRENT 与最近 daily，用 5～10 分钟无答案小测试回顾。
2. 模型 → 一次最小完整示例 → 补关键代码 → 撤去提示 → 独立复现 → 变式 → 排错 → 延迟复测。
3. 每次仅引入一个主要新概念；先预测结果，再运行，再解释差异。
4. API 同时讲参数、单位、返回值、异步行为、生命周期和失败路径。
5. 不一次性代写整套任务程序；首次示例与卡点对照可以提供完整小例子。
6. 允许查文档；独立复现指自己组织逻辑，不要求默写第三方接口。
7. 跟随跑通、源码归档、独立掌握分别记录；未实测明确标注。
8. 实际 Ubuntu 最终源码与日志归档后才记录为可复现，不用聊天草稿冒充最终代码。
9. 学习者决定项目范围；不擅自修改旧 ROS 2 工程或加入视觉/清洁功能。

每天记录：目标、实际完成、问题与原因、证据路径、提示程度、下一次测试。阶段完成要求能解释、能运行、能独立写最小实现、能改需求并定位至少一个问题。
