## 测试层次

1. 离线逻辑：假遥测驱动状态机，测试超时、数据过期、重复事件、未知状态与计数重置。
2. 最小 SITL：连接、遥测、原地起降、停转观测。
3. 单段 H→A、完整单轮、连续3轮。
4. 单独异常注入，不与正常连续成功计数混淆。
5. 干净构建和完整重启后的复现。

## 正常验收

| 项目 | 标准 |
|---|---|
| 起飞 | 稳定在起降平面上3.0±0.5m |
| 到位 | 水平误差≤0.5m、高度误差≤0.5m、水平速度≤0.3m/s持续2秒 |
| A降落 | 机体完整在平台内，无侧翻或异常碰撞 |
| 停转 | 飞控状态满足且全部仿真电机转速近零稳定，阈值预先锁定 |
| 等待 | 停转确认后≥10秒，未完成复检不解锁 |
| 返回 | 使用首次H，最终水平误差≤0.5m |
| 连续 | 同一仿真会话连续3轮，无人工操控、不重启；失败重计 |
| 记录 | 每轮任务日志、遥测、ULog、真值/转速、配置/版本可追溯 |

位置同时对照 Gazebo 真值，不能只用飞控估计评价自身误差。至少记录每轮最大/最终误差、稳定高度、等待时间、落点、是否停转、耗时和结果。冻结阈值前先确认真值与飞控坐标转换。

## 异常矩阵

| 注入 | 期望 |
|---|---|
| 启动无飞控/未定位 | 有界等待，失败不解锁 |
| 命令拒绝 | 保存返回原因，核对状态，不盲目重发 |
| 到位超时 | 进入异常出口，不直接降落在未确认的A点 |
| 着陆状态未知/电机不停 | 不启动再次起飞 |
| 等待期间健康失败 | 保持地面停机，结束或等待到配置超时 |
| 遥测停止或仿真暂停 | 不用陈旧数据推进，不自动起飞 |
| 应用/链路中断 | PX4按实测故障保护动作，恢复后不自动续飞 |
| 人工模式接管 | 停止自动命令，记录中止 |
| 日志路径不可写 | 启飞前阻止开始；飞行中标记失败并安全结束 |

所有故障注入先在离线/仿真执行。返航、降落或保持的适用条件必须在实际参数配置下验证；不以API调用成功代替结果验证。
